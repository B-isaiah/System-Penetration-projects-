# System Penetration & API Security Projects

## Overview
This repository contains structured penetration testing, API security assessments, and vulnerability research projects completed across multiple weeks.

## Focus Areas
- API Security Testing (JWT, VAPI, API Gateway)
- System Penetration Testing
- Privilege Escalation (Linux & Windows)
- Vulnerability Assessments
- Digital Forensics & Cryptography

## Tools Used
- Burp Suite
- Postman
- Metasploitable2
- John the Ripper
- Linux enumeration tools

## Repository Structure
- API Security
- System Penetration Testing
- Privilege Escalation
- Vulnerability Assessments
- Forensics & Cryptography

## Objective
To demonstrate practical offensive security skills including identification, exploitation, and documentation of system and API vulnerabilities.
